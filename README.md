# 💰 Personal Finance Tracker

A simple yet functional **React + Vite** application for tracking personal finances.  
Built as part of the **Web3Bridge Cohort XIV Pre-Qualification Test**, this project enables users to record, categorize, and analyze their income and expenses with ease.

---

## 🚀 Features

- ✅ Add, edit, and delete income/expense transactions  
- ✅ Include amount, date, category, and optional notes  
- ✅ Create and manage custom categories  
- ✅ Sort and filter transactions (by date, amount, category, or type)  
- ✅ Persistent data storage using **localStorage**  
- ✅ Export transactions as **CSV**  
- ✅ Visual summary with **Chart.js** (income vs expenses)  
- ✅ Responsive UI design  
- ✅ Bonus: Unit tests with **Vitest**

---

## 🧠 Tech Stack

- **React + Vite**
- **Chart.js + react-chartjs-2**
- **Vitest** (for testing)
- **LocalStorage** (for persistence)
- **CSS Grid / Flexbox** (for layout)
